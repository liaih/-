# 快速修圖 APP 規格與交接（給 Claude Code）

## 使用者與目標
Ailsa，晨陽設計（室內設計公司）。Windows、Canon EOS R5（CR3）。要做批次修圖 APP，輸出 JPG（sRGB、品質95，可選16-bit TIFF），之後進 Lightroom 細修。語言：繁體中文。

## 需求
1. 一次幾十組，自動分群；全程自動判斷哪張過曝、哪張過暗（不信 EXIF，因為會有開關燈）。
2. 同機位可能含：環境光多段曝光、每盞燈單獨亮起的多段曝光（吊燈／軌道燈／櫃體燈）、開門／關門。每機位開門版、關門版各輸出一張。
3. 去除雜物、室內線材：靜止物，無法靠多張比對。第一版：審核頁點選／塗抹 → SAM + LaMa（onnxruntime，DirectML 可選）。
4. 一鍵風格 = 通用 LR 預設（style_default.xmp，匯入 xmp 解析），不含遮色片（牆面／天花遮色片、Upright 透視校正都留在 LR 做，APP 不處理幾何）。
5. 打包 PyInstaller exe，介面 PySide6（第三階段）。

## 風格 xmp 數值（style_default.xmp）
WB 增量 temp -9 / tint +14；曝光 -0.06；對比 +7；亮部 -34；陰影 +76；白色 +35；黑色 -22；自然飽和度 +13；飽和度 +1；HSL 橘色飽和 -22、綠色飽和 -28；其餘為 0。白平衡是「增量」，基準用相機白平衡。
風格需通用，不針對單一案場。曝光須先自動校正到目標亮度再套風格（xmp 假設輸入為正常亮度）。目標亮度可由使用者的範例成品學習（見 samples）。

## 範例素材（使用者提供，JPG 縮小版 2576px，已無 EXIF）
- 吧檯機位 1O4A2712–2723（12 張）：環境光 2712–2716（亮→暗）、吊燈亮 2717/2718/2719、軌道燈亮 2720/2721、櫃體層板燈亮 2722/2723。
- 客廳機位 1O4A2780/2782/2784/2785：4 張曝光不同，無燈光變化，窗外過曝需從暗圖取回。
- LR 成品：2-4.jpg（只套 xmp，無遮色片，有 Upright 裁切）、LR2.jpg（完成版，有遮色片）。完工照燈全關，吊燈不發光。
→ 比對目標是 2-4.jpg，用特徵點 homography 對位後比較亮度／色彩統計。

## 已驗證（retouch/ 內程式）
- grouping.py：曝光不變的結構圖（log 亮度、去低頻、局部對比正規化）做 NCC，同機位 0.55–0.96、不同機位 ≈0，單連結閾值 0.35 完全正確分群。
- align.py：ECC translation（結構圖）；逐張對最相似且已對齊者並累加位移。實測 2716 真實位移約 +4px（兩個參考一致），燈光組約 +2px。cc<0.6 不採用。
- merge.py：valid_mask（gamma 0.05–0.95）、亮度轉換曲線校準（逐 bin 中位數、單調、兩端斜率外推）、light_difference（過曝像素視為下限，只在下限已高於另一張時算差異）。
  結果：環境光 5 張彼此差異 ≈0%；吊燈 2717 vs 2719 0.47%（同狀態），對環境光 ≈20%（燈光外溢到牆面）。

## 未解問題（接手第一件事）
1. 直接把每張校準到單一基準（2713）時，最暗的幾張（2718、2720、2721、2723）共同有效面積太小，校準失敗，差異矩陣失真（47–98%）。
   待做：改成「最大生成樹」逐級串接——每張只和共同有效面積最大的鄰居比對（用鄰居已校準的 R 當 x），再一路接回基準。該修改已寫好未套用也未測試。
2. 狀態分群：用 light_difference 的 D 矩陣做閾值聚類（預期 {2712–2716}、{2717,2718,2719}、{2720,2721}、{2722,2723}），需調閾值；軌道燈面積很小。
3. 合成：環境光 HDR 輻射量（hat 權重）為底；每個光狀態減去環境光得燈光層 Δ（≥0）；成品 = R_amb + Σ a_i·Δ_i，a_i 為每機位「燈光開關表」（預設 0，對齊她的完工照）。
4. 風格實作（尚未寫）：WB 增量→RGB 增益；曝光；對比（gamma 空間 S 曲線）；亮部／陰影用大半徑平滑底層做局部調整；白色／黑色調整黑白場；自然飽和度；HSL 依色相的平滑權重。近似 LR，需與 2-4.jpg 對照微調常數，並向使用者說明是近似。
5. 自動曝光：二分搜尋曝光，使套風格後亮度中位數 = 範例成品的目標值。
6. JPG 有相機曲線，所以才需轉換曲線校準；CR3 經 rawpy（use_camera_wb、no_auto_bright、16-bit）應近似線性，需實測 R5 CR3（含 C-RAW）能否讀、各張白平衡是否一致。
7. 開門／關門差異：尚無素材，需使用者提供；門區域用兩狀態差異遮罩合成。
8. 線材／雜物補圖（SAM + LaMa）、審核頁、PySide6 介面、PyInstaller：第二、三階段。
